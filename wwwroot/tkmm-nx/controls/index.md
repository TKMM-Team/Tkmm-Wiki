# Joy-Con Controls

<br>

<div style="max-width: 500px; margin-left: 0; margin-right: auto;">

| Button | Action |
|:---:|:---:|
| A | Key. ENTER |
| B | Key. BACKSPACE |
| X | Key. ESCAPE |
| L | Key. PAGEUP (Switch to previous tab) |
| R | Key. PAGEDOWN (Switch to next tab) |
| ZL | Right Mouse Click |
| ZR | Left Mouse Click |
| Left Stick | Controls the mouse |
| Right Stick | Controls scrolling |
| R3 | Middle Mouse Click |
| Home | Open Reboot2Config Menu |
| Capture | Take a screenshot |
| D-Pad Up | Key. UP |
| D-Pad Down | Key. DOWN |
| D-Pad Left | Key. LEFT |
| D-Pad Right | Key. RIGHT |

</div>

<br>

If a button is missing from the list, it simply means it's unused.

<br>

> [!IMPORTANT]
> For Joy-Con controls to work in TKMM-NX, it is required to go to Hekate, press `Nyx Settings` on the main page, then press `Dump Joy-Con BT`
